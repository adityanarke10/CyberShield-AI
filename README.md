# CyberShield AI

## AI-Powered Web Application Security Assessment Platform

CyberShield AI is an intelligent cybersecurity platform developed using Python and Flask. The platform performs automated website security assessments by analyzing HTTP security headers, SSL/TLS certificates, open ports, and other security configurations. It generates AI-powered security recommendations and professional PDF vulnerability assessment reports.

## Features

- User Authentication
- Website Security Assessment
- Security Header Analysis
- SSL Certificate Analysis
- Port Scanning (Nmap)
- AI Security Recommendations (Google Gemini)
- Risk Score Calculation
- PDF Report Generation
- Scan History

## Technology Stack

- Python
- Flask
- SQLite
- Bootstrap 5
- Google Gemini API
- Nmap
- BeautifulSoup
- Requests
- ReportLab
